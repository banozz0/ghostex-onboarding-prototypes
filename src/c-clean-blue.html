Why Ghostex?

Codex and Claude are the agents.
Ghostex is the workspace around them.

You keep your existing agent subscriptions and CLIs. Ghostex doesn't replace them.

01 · MULTI-AGENT

Run several agents at once

Claude on the refactor, Codex on tests, another terminal on the server — organized by project instead of scattered windows.

02 · REVIEW

See what the agent is building

Open the embedded Chromium browser, inspect DevTools, review code, Markdown, diffs, and generated docs without leaving the workspace.

03 · PERSISTENCE

Your sessions survive the UI

Agent sessions stay attachable. Restart Ghostex, switch machines, search old prompts, and resume where you stopped.

04 · ORCHESTRATION

Let agents work together

Claude can launch Codex sub-agents. Work can move through a project board instead of living inside one chat thread.

05 · MOBILE

Walk away without losing control

Check running sessions, reply, or resume from your phone while the actual workload stays on your computer or remote host.

06 · CHOICE

Use the interface that fits

Terminal when you need raw power. Chat view when you want readability. Browser and IDE when it's time to inspect the result.
